# App icon

## Decision

The Mist icon is a bridge glyph derived from the user's reference: a shallow
arch with vertical hangers over a deck, in warm sand ink on a dark charcoal
background.

It is authored as **SVG**, not generated as a bitmap. A flat monochrome mark is
better served by vector: it stays crisp at every density, maps directly onto
Android adaptive icons (background/foreground/monochrome layers), and remains
editable in git. The built-in image generation tool was also unavailable in the
session where this was requested.

## Sources

- `apps/mobile/design/app-icon.svg` — canonical 1024x1024 source.
- `apps/mobile/android/src/main/res/drawable/ic_launcher_foreground.xml`,
  `ic_launcher_background.xml`, `ic_launcher_monochrome.xml` — adaptive layers.
- `mipmap-anydpi-v26/ic_launcher{,_round}.xml` — adaptive icon definitions.
- `mipmap-*/ic_launcher{,_round}.png` — legacy raster fallbacks at 48/72/96/144/192 px.

## Regenerating the rasters

```sh
cd apps/mobile/android/src/main/res
for spec in mdpi:48 hdpi:72 xhdpi:96 xxhdpi:144 xxxhdpi:192; do
  d=${spec%%:*}; px=${spec##*:}
  rsvg-convert -w $px -h $px ../../../design/app-icon.svg -o mipmap-$d/ic_launcher.png
  cp mipmap-$d/ic_launcher.png mipmap-$d/ic_launcher_round.png
done
```

Rendering notes: gradients on horizontal/vertical strokes must use
`gradientUnits="userSpaceOnUse"`; with object bounding box units a zero-area
bounding box makes the gradient vanish. ImageMagick's SVG parser also drops
`H`/`V` path commands, so the source uses explicit coordinates.
